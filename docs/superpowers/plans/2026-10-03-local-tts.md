# Local TTS Implementation Plan

> Execute inline using superpowers:executing-plans and test-driven-development.

**Goal:** Integrate offline Vietnamese narration with exactly two fixed voices into Cre-vid.
**Architecture:** Node worker owns a Python ONNX subprocess, sends JSON lines, receives WAV paths. One pinned model and two presets live in local storage. Existing media ingestion and job revision handling remain authoritative.
**Tech Stack:** Next.js 16.3.6, TypeScript, Python 3.12, VieNeu-TTS 3.8.3 / ONNX, FFmpeg.
**Spec:** ../specs/2026-10-03-local-tts-design.md

## Constraints and review focus

- Only `male` (Minh Đức) and `female` (Mai Anh); no cloud fallback.
- Runtime is offline; setup downloads and locks model revisions and dependencies.
- Reject missing model, invalid voice/text/speed before expensive inference.
- Cancel/timeout kills inference, cleans temporary files, allows next job.
- WAV format must match ingestion; preserve old projects and stale-text handling.
- Readiness requires successful installation/smoke test plus required files, not a directory alone.
- Test empty/corrupt output, subprocess failures, missing assets, cancellation and changed text.
